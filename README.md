# 风老师 · 言语理解 AI 助教（PWA）

把超格·四诗风雅颂（学生口中的"四哥/风老师"）的**言语理解课堂体系**蒸馏进一个可离线使用的 PWA 网页应用。风格、解题逻辑、口头禅、易错点体系全部来自真实讲义（`课件\_ocr\*.txt` 与《四哥克隆体特征档案.md》），不自创、不走通用模板。

> 谁可以用：公考备考者。拍照不会的题、随机带练、搜知识点、自动错题本 + 薄弱点记忆加权。

---

## 一、核心功能

| 功能 | 说明 |
|---|---|
| 💬 对话答疑 | 直接把题目/问题粘贴进来，风老师按"答题固定流程"讲解 |
| 📷 拍照 / 相册搜题 | 原图直发**视觉模型**（无任何前端 OCR）→ 可裁剪 / 旋转 / 缩放 / 模糊温柔提示 |
| 📝 随机出题 | 内置 **51 道精选真题**（标答取自题本答案行或讲义批注，答案可靠）；按薄弱题型加权、可选题型 |
| 🧠 超级记忆 | 9 大题型 + 踩坑标签自动加权；"已掌握"一键压权重；主动复盘 + 学习小结 |
| 📖 知识点速查 | 40 张从讲义蒸馏的知识点卡，本地秒搜，可一键请老师讲透 |
| ❌ 错题本 | 答错自动收录；题型筛选；标掌握/删除；导出 Markdown / JSON |
| 🗂 讲义上传（本地RAG） | 拖入 `_ocr\*.txt` 等讲义文本 → 讲解时可自动检索相关片段做参考 |
| 🎚 讲解三档 | 简洁 / 标准 / 深度精讲（风老师复盘模式） |
| 🔁 双模式 | 在线 DeepSeek（或其他 OpenAI 兼容 API）＋ 本地 Ollama（离线无网） |
| 📲 PWA | 可"添加到主屏幕"、全屏独立运行、刷新不丢记忆（localStorage + IndexedDB） |

## 二、最快上手

**方式 A：双击即用（基本功能）**
直接双击 `index.html` 用浏览器打开即可聊天/出题/速查；识图与 PWA 安装建议走 B 或部署。

**方式 B：本地服务器（推荐，含 PWA）**
双击 `启动本地测试.bat`（或在文件夹里运行 `node server.js`），浏览器会自动打开 `http://localhost:8787`。

**方式 C：部署到公网（手机也能用、可装桌面）**
- **Cloudflare Pages**：把本文件夹直接拖进 `https://dash.cloudflare.com → Workers 和 Pages → 创建 → Pages → 上传资源`。
- **GitHub Pages**：本文件夹推到一个仓库，Settings → Pages → 部署分支根目录。
- 手机访问部署后的 https 地址 → 浏览器菜单"添加到主屏幕" → 像独立 App 一样用（拍照/安装都需要 https，localhost 除外）。

## 三、模型配置（第一次用必看）

点右上 **☰ → 设置**，二选一：

1. **在线 API（DeepSeek 等）**
   - 接口地址默认 `https://api.deepseek.com/v1`；
   - 文本模型填你账号可用的模型 id（如 `deepseek-chat`，也可填新版如 `deepseek-v4-flash`——**以你的账号实际模型为准**）；
   - **API Key** 填 `sk-…`（只存在你这台浏览器里，不联网上传）。
2. **本地 Ollama（离线无网）**
   - 需先装 [Ollama](https://ollama.com) 并拉模型，如 `ollama pull qwen2.5:7b`；
   - 地址默认 `http://localhost:11434/v1`；文本模型 `qwen2.5:7b`；
   - ⚠️ 让网页能连 Ollama，需给 Ollama 设环境变量 `OLLAMA_ORIGINS=*` 后重启（否则浏览器 CORS 会拦截）。

填好后点"测试连接"，显示 ✓ 即可开讲。

### 识图（拍照搜题）需要"视觉模型"
题目图片是**原图直接发给模型**，不经任何前端 OCR，所以后端必须**支持图片**：
- 在线：若你的 DeepSeek 接口收不了图，请在设置里"视觉模型"填一个支持多模态的模型，或换支持视觉的兼容端点；
- 本地：把"视觉模型"填成 `qwen2.5-vl:7b` 或 `llava`（需 `ollama pull` 对应模型）。
发图被拒时应用会给出温柔提示，不会假装识别。

## 四、把讲义喂给"本地记忆"

打开 **☰ → 讲义**，把 `课件\_ocr\*.txt`（已经 OCR 好的讲义全文，19 个文件）一次多选或整文件夹拖进去即可。勾选"讲解时自动检索上传讲义"后，讲题/速查时会自动在本地检索并引用相关片段。所有文本只存你的浏览器（IndexedDB），不上传。

`PDF` 建议先用任意工具转成 txt 再导入（本项目保持纯静态、离线可用，不内嵌 PDF 解析器）。

## 六、自检 & 常见问题

```bash
node engine-test.js    # 期望：RESULT: 31 passed, 0 failed
```

| 现象 | 处理 |
|---|---|
| 发送后提示"网络请求失败/连不上 Ollama" | 检查设置里 Key/地址；Ollama 加 `OLLAMA_ORIGINS=*` 重启 |
| 发图提示"不支持图片输入" | 换支持视觉的模型（本地 `qwen2.5-vl` / `llava` 等）；或点设置里 **「识图自检」**，把回显的"接口原话"发我以适配该接口格式 |
| 出题按钮提示先填 Key | 离线请切到"本地 Ollama"模式 |
| 手机上不能拍照/不能安装 | 部署到 https（Cloudflare/GitHub Pages），不要用局域网 http |
| 聊天记录/记忆被清 | 数据只存本浏览器；清缓存或换浏览器会丢，属正常隐私边界 |

隐私：除你自己配置的模型接口外，代码不调用任何第三方；答题数据、错题本、导入讲义都只存在本地浏览器。
